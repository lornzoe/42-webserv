webserv

HTTP/1.1 server written in C++98 — 42 project

Static Serving

This page is a static HTML file served directly from the filesystem.

GET /index.html

Directory Listing

Browse uploaded files. autoindex on generates this listing dynamically.

GET /files

File Upload

POST a file to /upload. It will be saved in www/uploads/.

File Delete

Send a DELETE request to remove a file from www/uploads/.

CGI

Executes a Python CGI script. Environment variables and query strings are passed through.

GET /cgi-bin/info.py  |  /cgi-bin/info.py?name=webserv

Redirect

The location /old-page issues a 301 redirect to /index.html.

301 /old-page

Second Server (port 8081)

A second server block listens on port 8081 with directory listing enabled at root.

GET http://localhost:8081/
